# Hospital Internship – Software Engineering Work Samples
## Overview
This repository showcases selected software engineering work from my cooperative training at the Digital Health Department at King Abdulaziz Hospital in Makkah, Saudi Arabia.
During my training, I contributed to the full-stack development and enhancement of four internal hospital web systems, working across front-end, back-end, databases, REST APIs, testing, deployment, and technical documentation.

## 1. Shift Management System
A web-based system designed to organize hospital staff schedules and replace manual scheduling processes.
### Key Features
- Employee, department manager, and administrator dashboards
- Shift and roster management
- Shift requests and approvals
- Attendance monitoring
- Authentication and role-based permissions
- Arabic and English interfaces

### My Contribution
Contributed to developing system interfaces, database structures, back-end functionality, REST APIs, testing, deployment, and documentation.
